# Spring Studio

面向 Galgame 创作的本地剧本写作平台，支持结构化台词与旁白编辑、AI 辅助写作，以及 LetsGal 原生工程导入导出。

## 主要功能

- **剧本编辑**：按章节和场景组织故事，分别编写角色台词与旁白，保留富文本和演出节点。
- **AI 辅助写作**：生成角色台词、扩写或修改选段、续写节拍，提供行动、剧情和设定建议。
- **作者审阅**：对照原稿查看候选，手动编辑、检查、修订后决定采用。
- **剧情检查**：视角、全篇文风、设定一致性，以及剧情衔接、因果和节奏检查。
- **设定管理**：角色卡、口吻、世界观、路线事实、知情记录和创作笔记。
- **本地工程**：自动保存、撤销重做、恢复点和完整工程备份。
- **LetsGal 适配**：导入原生工程，保留身份、分支、资源和演出信息，编辑后导出独立工程。

## 下载与启动

前往 [最新版本](https://github.com/spr10g/spring_studio/releases/latest) 下载 Windows x64 便携 EXE，双击运行。

## 开始创作

1. 新建写作工程，或点击“导入 LetsGal”选择包含 `project.json` 的工程文件夹。
2. 在左侧选择章节与场景，在中间编写台词和旁白。
3. 在右侧“接口设置”配置兼容 Chat Completions 的 AI 服务。
4. 选择写作意图，预览发送范围，生成并审阅候选。
5. 完成创作后，点击“导出剧本”，在 LetsGal 中打开导出的工程文件夹。

## 运行环境

Windows 10 / 11，64 位。本地编辑可离线使用，AI 功能使用自行配置的模型服务。
